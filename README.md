# GPT 과제 대행소 🔍

> AI 챗봇 '마니봇'의 요약 속 오류를 직접 찾아 바로잡으며 할루시네이션 대응법을 익히는 웹 미니게임

- **기간**: 2025.03.03 ~ 2025.06.19
- **소속**: 서울여자대학교 바롬종합설계프로젝트 · 404: Ethics Not Found 팀 (5인)
- **역할**: 팀장 · 게임 개발 담당

<br>

## 기획 배경

사전 설문에서 응답자의 94%가 AI를 사용하지만, 84.9%는 할루시네이션에 대응하는 방법을 모르고 있었습니다.
개념 설명만으로는 실제 검증 행동으로 이어지기 어렵다고 판단해, 오류를 직접 찾아보는 체험형 콘텐츠를 만들었습니다.
게임은 AI 할루시네이션 대응 캠페인의 핵심 체험 콘텐츠로, 현장 참여자가 QR 코드로 접속해 플레이했습니다.

<br>

## 게임 방법

플레이어는 마니봇과 함께 요약 과제를 수행합니다. 마니봇이 내놓은 요약이 믿을 만한지 스스로 판단하고, 명령어로 검증하고 수정하며 제한 시간 안에 과제를 완성해야 합니다.

| 명령어 | 검증 행동 | 피드백 |
|---|---|---|
| 요약해줘 | AI에게 요약 요청 | 오류가 섞인 요약본 제공 |
| 출처 알려줘 | 정보의 근거 확인 | 원문 출처 링크 제공 |
| 요약 재확인해줘 | 결과 다시 검토 요청 | 오류를 바로잡은 요약본 제공 |

검증 행동을 할수록 가산점이 쌓이고, 과제를 제출하면 최종 점수에 따라 등급이 산출됩니다.

<br>

## 주요 기능

- **상태 흐름 관리**: 시작 → 과제 제시 → 상호작용 → 제출 → 종료의 게임 단계를 세션 상태로 관리
- **5분 타이머**: 제한 시간이 지나면 게임이 자동 종료
- **동일한 플레이 기준**: 오류를 심은 요약본과 정답본을 미리 설계해 모든 참여자가 같은 조건에서 플레이
- **점수·등급 시스템**: 명령어별 가산점과 제출 시 등급 산출
- **웹 실행**: 설치 없이 브라우저에서 바로 플레이

<br>

## 결과

- 웹 게임 참여자 55명
- 할루시네이션 대응 방법을 안다는 응답 10명 → 24명, 발생 원인을 안다는 응답 13명 → 25명 (중복응답)
- 참여자 만족도 93%
